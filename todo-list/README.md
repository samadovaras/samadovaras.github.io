
# To-Do List App

A simple and responsive task management application built with HTML, CSS and JavaScript.

## Features

- Add new tasks
- Mark tasks as completed
- Delete tasks
- Filter tasks (All, Active, Completed)
- Save tasks using browser localStorage
- Responsive dark theme design

## Technologies Used

- HTML5
- CSS3
- JavaScript
- LocalStorage

## What I Learned

This project helped me practice JavaScript functions, arrays, DOM manipulation, event handling and browser storage.
